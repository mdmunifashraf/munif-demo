# munif-demo

Demo Personal Portfolio

This repository contains a simple, single-page personal portfolio website created as a practical exercise while learning foundational HTML and CSS. It serves to demonstrate basic web structure, styling concepts, and core mechanics rather than advanced frontend development.

Features:
1. Includes distinct sections for an introduction, educational background, technical skills, and contact information.   
2. Implements a sticky, transparent navigation header that remains fixed at the top of the viewport.   
3. Utilizes smooth scrolling behavior for seamless transitions between page sections via anchor links.   
4. Uses Flexbox to center elements and structure the layout, such as aligning content within the main containers.   
5. Features custom background images for different sections and box-shadow styling for visual depth.

Usage:

To view this project locally, download the project files and open index.html in any modern web browser. No local server or build environment is required.
